@@ShortDescription
Test the real capacity and speed of USB sticks and SD cards, spot fakes, clear out duplicate files, wipe free space to make recovery harder and keep a file behind a password - from a window or the command line. No accounts, no ads, no telemetry.

@@Description
Is your USB stick or SD card really as big as its label says? FileDO writes real data to it and reads it back, so a fake is caught before it swallows your files. The test fills the free space, so it takes time on large media. FileDO also helps you look after the data on any drive: it finds duplicate files, compares and copies folders, wipes free space to make recovery harder, and keeps a file behind a password.

Open it from the Start menu, or type filedo in any terminal - the same engine runs behind both.

CHECK
- Capacity test: writes real data across the free space and reads it back, so a USB stick or SD card that promises more space than it has is caught before it swallows your files. Start with an empty card: only free space is tested, and a large card takes time.
- Speed test for disks, folders and network shares, with detailed timing.

TIDY AND MOVE
- Duplicate finder: matches files by content, with a hash cache that is reused between runs; a duplicate is deleted only after a byte-for-byte check; delete or move duplicates by oldest, newest or name.
- Compare two folders, and copy large trees with live progress, an ETA and care for slow or damaged disks.

ERASE
- Fill the free space with data and delete it again, or overwrite a single file before removing it, to make recovery harder; on SSDs and copy-on-write disks that promises nothing. Emptying a folder is a plain delete, and it asks you to type WIPE first. Drive roots, junctions and system temp folders are never forced.

PROTECT
- Pack one file into a password-protected .fd-sec container, get the original back, or open the contents in the program they belong to without unpacking - from a read-only copy that only your account can read and that is removed when you are done with it. An empty password is accepted and means obfuscation only, not secrecy; FileDO says so where you type it. The container format is published in full, so your data can be read without FileDO.

VIRTUAL DISKS
- A .fdd container holds a whole volume in one file. In this edition you can create one, read its facts, read it through for damage, export it as a raw image or a VHD that Windows opens by itself, grow or compact it, copy it, change its password or remove it - no administrator rights needed. Without a password a container is obfuscated, not encrypted: anyone with the file and FileDO can read it. Mounting a container as a drive letter is not available in this edition (see below).

PRIVATE BY DESIGN
FileDO runs entirely on your device. It never connects to the internet or to any other computer, and it has no telemetry, no ads and no accounts. It is open source: https://github.com/SerZhyAle/FileDO

GOOD TO KNOW
- This is the Microsoft Store edition. It does not add Explorer context-menu entries; those come with the MSI installer. It does claim the .fd-sec file type, so double-clicking a container opens FileDO. The same operations are available in the window and with the filedo command.
- FileDO needs full-trust desktop access to read and write raw disk and device data: capacity testing, speed benchmarking and wiping cannot work without it. Wipe and fill destroy data by design and always confirm before touching drive roots or system folders.
- Mounting .fdd virtual disks is not available in the Microsoft Store edition: a packaged app can neither configure the Windows iSCSI initiator nor ask for administrator rights. Double-clicking a .fdd opens FileDO on that container, which can be read through for damage and exported here; to mount one, use the setup or the portable build from GitHub.
- Windows 10 version 1903 or later.
