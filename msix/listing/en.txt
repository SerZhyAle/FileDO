@@ShortDescription
Test the real capacity and speed of drives and SD cards, spot fake flash, wipe data securely, clear out duplicate files and lock a file behind a password - from a window or the command line. No network, no accounts, no ads.

@@Description
FileDO tells you whether a drive is what it claims to be, and gives you the tools to look after the data on it.

Open it from the Start menu, or type filedo in any terminal - the same engine runs behind both.

CHECK
- Capacity test: writes real data across the whole device and reads it back, so a USB stick or SD card that promises more space than it has is caught before it swallows your files.
- Speed test for disks, folders and network shares, with detailed timing.

TIDY AND MOVE
- Duplicate finder: MD5 hashing with a cache that is reused between runs; delete or move duplicates by oldest, newest or name.
- Compare two folders, and copy large trees with live progress, an ETA and care for slow or damaged disks.

ERASE
- Wipe a folder or fill the free space to make recovery harder. Wipe always asks you to type WIPE, and drive roots, junctions and system temp folders are never forced.

PROTECT
- Pack one file into a password-protected .fd-sec container, get the original back, or open the contents in the program they belong to without unpacking - from a read-only copy that only your account can read and that is removed when you are done with it. An empty password is accepted and means obfuscation only, not secrecy; FileDO says so where you type it. The container format is published in full, so your data can be read without FileDO.

PRIVATE BY DESIGN
FileDO runs entirely on your device. It has no network code, no telemetry, no ads and no accounts. It is open source: https://github.com/SerZhyAle/FileDO

GOOD TO KNOW
- This is the Microsoft Store edition. It does not add Explorer context-menu entries; those come with the MSI installer. It does claim the .fd-sec file type, so double-clicking a container opens FileDO. The same operations are available in the window and with the filedo command.
- FileDO needs full-trust desktop access to read and write raw disk and device data: capacity testing, speed benchmarking and secure wiping cannot work without it. Wipe and fill destroy data by design and always confirm before touching drive roots or system folders.
- Windows 10 version 1903 or later.
