## What this repository must do to stay conformant

- **The agent-rules file sits at the root.** `AGENTS.md` carries the rules; `CLAUDE.md` is a bare pointer
  to it (rule 1).
- **`docs/contracts/<ID>.md` holds pointers, never copies**, one per contract produced or consumed, with
  `docs/contracts/README.md` as the index. A pointer stays short enough to be read as a pointer (rule 2).
- **`README.md` and `LICENSE` stay at the root** (rule 4).
- **The ledger is where the stamp says**: shape 4, no ledger file, release notes generated by the release
  workflow (rule 5).
- **`PLAN/done/` is an archive and stays frozen** (rule 6).
- Known open point: `PLAN/SP-XXXX name.md` is this repository's own spec-id scheme, not a type prefix
  (rule 3); a proposal to the owner asks for the carve-out the canon prose already makes.
