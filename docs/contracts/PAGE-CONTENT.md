## What this repository must do to stay conformant

- **Landing hierarchy.** Keep one neutral `#get` Install action in the header; lead with an outcome, who it helps and scenario proof; then provide a safe real-channel start, three to six visible outcome-led capability groups, guides, details and the standard footer.
- **Language switcher.** Synchronized multilingual switcher (RU / EN / UA), language state persisted in `sza-lang`.
- **No emoji in content.** Meaningful SVG glyphs or plain text instead of emoji icons.
- **Direct download links.** Stable GitHub release link integration without hardcoded unstable asset paths.
