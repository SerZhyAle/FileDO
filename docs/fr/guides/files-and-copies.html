Guide · fichiers et dossiers

Obtenez d’abord une liste ou un rapport. Décidez de supprimer plus tard.

FileDO vous aide à voir les doublons, les différences entre dossiers et la progression d’une copie. Un bon premier passage produit une liste claire, un rapport ou une copie de sauvegarde, pas une suppression immédiate.

Trois situations courantes

Libérer de l’espace

Trouvez les fichiers identiques, enregistrez ou relisez la liste, puis décidez de ce que vous gardez.

filedo D:\Media check-duplicates

Faire une copie à emporter

Copiez le dossier source vers un emplacement de sauvegarde ou un autre disque avec une progression visible. La copie démarre dès le premier fichier trouvé ; ajoutez --precount pour compter d’abord toute l’arborescence et voir un temps restant exact.

filedo C:\Source copy D:\Backup

Vérifier un dossier de sauvegarde

Comparez deux dossiers par chemins relatifs et tailles, obtenez un rapport et examinez les différences.

filedo compare D:\Data E:\Backup

Un parcours sûr

Suppression

Les modes del des doublons et de la comparaison modifient les données. Ils ne sont volontairement pas montrés en premier exemple : obtenez d’abord une liste ou un rapport, puis sauvegardez et vérifiez le chemin à la main.

  1. Désignez un dossier précis plutôt qu’un disque entier quand la tâche concerne une seule archive.
  2. Lancez la recherche de doublons ou la comparaison sans mode de suppression et examinez le résultat.
  3. Avant toute suppression, faites une copie distincte des fichiers que vous voulez garder.

Ce que signifie la comparaison

La comparaison associe les chemins relatifs et la taille des fichiers ; les modes old/new utilisent l’heure de modification. La correspondance des chemins sous Windows ne tient pas compte de la casse. Les rapports sont enregistrés sous compare_report_*.log, et les journaux de suppression sous delete_report_<mode>_*.log.

Pour une vérification automatisée, utilisez filedo compare D:\Data E:\Backup --strict : des chemins relatifs, tailles et heures de modification identiques renvoient le code 0 (Passed), une différence renvoie le code 1 (Failed), et une comparaison incomplète renvoie le code 2 (Not proven). Avec --by-hash, les paires de même taille sont comparées par leur contenu plutôt que par l’heure. Un compare simple reste un rapport avec le code 0 (Done) ; --strict ne peut pas se combiner avec la suppression.
