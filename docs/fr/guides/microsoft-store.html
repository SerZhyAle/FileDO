Guide · Microsoft Store

Utilisez FileDO depuis le Microsoft Store et sachez ce que cette version ne peut pas faire.

La version du Microsoft Store est le même FileDO, installé et mis à jour par le Store : la fenêtre FileDO et la commande filedo. C’est une application empaquetée, et une application empaquetée ne peut ni configurer l’initiateur iSCSI de Windows ni demander des droits d’administrateur ; elle ne peut donc pas monter de disques virtuels. La plupart des limites figurent aussi dans le guide de la fonction qu’elles touchent ; cette page les réunit au même endroit.

1. L’obtenir

Installez FileDO depuis sa page du Microsoft Store ; ensuite, le Store tient le paquet à jour.

Microsoft Store

Installée et mise à jour par le Store, et signée par Microsoft lors de la certification. Cette version ne peut pas monter de disques virtuels et n’ajoute aucune entrée au menu de l’Explorateur ; la section 3 liste ce qui lui manque d’autre.

Obtenir sur le Microsoft Store

Setup EXE, MSI, ZIP et winget

Les autres versions peuvent monter des disques virtuels. Le setup EXE, le MSI et le ZIP de GitHub ne sont pas signés numériquement ; Windows peut donc afficher un avertissement au premier lancement.

Toutes les façons d’installerWindows vous a averti au sujet de FileDO

2. Ce que vous obtenez

Un paquet, deux entrées : la fenêtre FileDO et la commande filedo.

La fenêtre FileDO

Une page par tâche, et une page « Commande » qui construit et exécute n’importe quelle commande. Lancez-la depuis le menu Démarrer.

Travailler dans une fenêtre

La commande filedo

Tapez filedo dans n’importe quel terminal. Le même moteur tourne derrière la fenêtre et la commande.

Les mêmes outils

Le test de capacité, le test de vitesse, la recherche de doublons, la comparaison et la copie de dossiers, l’effacement et le remplissage, et les fichiers secrets sont dans cette version comme dans les autres.

3. Ce que cette version ne fait pas

Quand une commande ne pourrait jamais fonctionner dans cette version, la fenêtre l’omet au lieu de la griser : le Gestionnaire de disques, par exemple, n’affiche aucun contrôle de montage. La plupart de ces limites figurent aussi dans le guide de la fonction qu’elles touchent.

Pas de montage de disques virtuels

Une application empaquetée ne peut ni configurer l’initiateur iSCSI de Windows ni demander des droits d’administrateur ; cette version ne peut donc pas monter un disque virtuel comme lecteur. Les commandes qui exigent un montage se terminent avec le code de sortie 6 (non pris en charge).

Ce que Windows doit fournir

Pas de disques sur partition

Dans cette version, un disque virtuel ne peut résider que dans un fichier. vd disks le dit, toute commande de partition se termine avec le code de sortie 6, et « Nouveau disque.. » dans le Gestionnaire de disques ne propose que le fichier.

Disques sur partition

Pas de partage via Fast Media Sorter & Sharing

Le partage d’un disque via Fast Media Sorter & Sharing est fermé dans cette version, et le Gestionnaire de disques n’affiche aucune action de partage. Utilisez pour cela l’une des autres versions.

Ce qu’il faut au préalable

Pas d’entrées dans le menu de l’Explorateur

Le groupe « File DO.. » du menu contextuel ne fait pas partie de cette version : une version empaquetée ne peut l’obtenir que par un gestionnaire shell signé, et cette version n’en inclut pas. Le setup EXE et le MSI l’ajoutent.

Installation et menu de l’Explorateur

Les réglages Windows restent dans Windows

Dans la page « Réglages », « Lancer au démarrage de Windows » ouvre les Paramètres Windows, « Applications - Démarrage » : l’entrée est désactivée tant que vous ne l’y activez pas, et le Gestionnaire des tâches peut aussi la gérer. Le bouton « Désactiver la lecture automatique de Windows » n’est pas proposé ; à sa place, « Paramètres de lecture automatique de Windows.. » ouvre la page de Windows.

4. Ce qui fonctionne toujours avec les conteneurs

Lire et modifier un conteneur n’exige pas de montage ; cela fonctionne donc ici.

Conteneurs .fd-sec

Double-cliquez sur un fichier .fd-sec : la fenêtre FileDO s’ouvre sur la page « Ouvrir un fichier secret » avec ce conteneur déjà choisi, et le mot de passe est demandé là.

Fichiers secrets

Disques virtuels .fdd

Double-cliquez sur un fichier .fdd : la fenêtre FileDO s’ouvre sur ce conteneur et dit clairement que cette version ne peut pas monter. Vous pouvez toujours créer un conteneur, lire ses infos, le vérifier, l’exporter, l’agrandir, le compacter, le copier, changer son mot de passe ou le supprimer, sans droits d’administrateur.

Lire sans monter

5. Signature, autorisations et données

Cette section dit la même chose que la page de l’avertissement Windows et la page de confidentialité.

Signée par Microsoft

Microsoft signe le paquet lors de la certification ; cette version n’affiche donc aucun des avertissements Windows que le setup EXE, le MSI et le ZIP de GitHub peuvent afficher : ils ne sont pas signés numériquement.

Windows vous a averti au sujet de FileDO

Une autorisation, aucun réseau

Le paquet déclare une seule capacité, runFullTrust, qui permet l’accès direct au disque, et aucune capacité Internet. FileDO ne collecte rien : ni télémétrie, ni analyse, ni publicité, ni compte.
