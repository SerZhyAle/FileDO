Fonctionnalités

Ce que FileDO vérifie et fait

Les opérations sont regroupées par tâche. Les vérifications et les rapports ne modifient aucune donnée ; la suppression et le nettoyage se lancent séparément.

01

Vérifier le stockage

Contrôlez la capacité d’une clé USB ou d’une carte SD et mesurez les vitesses de lecture et d’écriture.

02

Vérifier la lecture

Repérez les fichiers qui se lisent avec des erreurs ou des blocages persistants.

03

Trouver les doublons

Examinez les groupes de doublons et enregistrez la liste avant de supprimer.

04

Copier et comparer

Copiez avec suivi de progression ou obtenez un rapport des différences entre dossiers.

Quand vous êtes prêt

Installation

Le programme d’installation Windows x64 : téléchargez un seul fichier et lancez-le. Les autres voies sont le Microsoft Store, winget, un ZIP portable et le MSI seul ; chaque lien ci-dessous mène toujours à la dernière version.

Télécharger pour Windows (setup.exe)

Windows 10 et 11, x64 · un seul fichier, sans ligne de commande · · Mo · SHA256

Sans signature de code : Windows peut afficher « Windows a protégé votre ordinateur » et demander l’autorisation d’un administrateur. Vérifiez le SHA256, puis choisissez « Informations complémentaires » et « Exécuter quand même ». Pourquoi, et sur quoi cliquer

winget install SerZhyAle.FileDO
Microsoft StorePortable ZIPMSIGitHub ReleasesCode source
  1. Lancez le programme d’installation, installez avec la commande winget ci-dessus, ou extrayez le ZIP depuis Releases.
  2. Ouvrez PowerShell ou cmd et inspectez d’abord le disque.
  3. Choisissez ensuite seulement un test, une mesure de vitesse, une copie ou une recherche de doublons.
filedo E: info
Important

Remplacez E: par votre cible. Cette commande affiche des informations et ne supprime aucun fichier.

Programme d’installation

Le fichier FileDO-<version>-setup.exe des Releases installe FileDO comme un programme Windows ordinaire : filedo dans le PATH, deux entrées du menu Démarrer (FileDO et FileDO Disk Manager) et une icône sur le bureau, ainsi que - en fonctionnalité désélectionnable - le groupe File DO.. dans le menu contextuel de chaque fichier et le type de document .fd-sec. winget et le ZIP n’enregistrent rien ; filedo fdsec register ajoute les mêmes entrées. Principales fonctionnalités

Après la vérification sans risque, utilisez une opération pour une tâche précise.

Capacité & vitesse

Tests de capacité et de performance pour les disques, les dossiers et les chemins réseau.

Contrôle de lecture

Contrôles de lecture avec rapports et réglages pour les supports HDD/USB lents. --max-files N lit au plus N fichiers (0 signifie sans limite) ; --resume réussit lorsque tous les fichiers ont déjà été vérifiés et restent inchangés.

Doublons

Correspondance par contenu avec cache ; enregistrez une liste et traitez-la plus tard.

Copie & comparaison

Copie avec progression et délais d’attente, plus rapports des différences entre dossiers. compare --strict renvoie le code 1 en cas de différences et le code 2 si la comparaison est incomplète.

Effacer & remplir

wipe supprime le contenu d’un dossier - une suppression ordinaire, la récupération reste possible tant que l’espace n’est pas réutilisé ; fill … del remplit l’espace libre de données puis les supprime, et sur un seul fichier wipe écrase le fichier avant de le retirer, les deux pour compliquer la récupération. wipe vous demande de saisir WIPE ; les racines de disque/partage, les points d’analyse et le dossier TEMP du système exigent une confirmation interactive même avec --force. Aucune de ces actions ne peut être annulée.

Fichiers secrets

Un fichier entre dans un conteneur .fd-sec derrière un mot de passe, puis en ressort ; un double-clic ouvre le contenu dans le programme auquel il appartient, à partir d’une copie qui est ensuite retirée. Un mot de passe vide n’est qu’un camouflage, et le programme le dit clairement.

Disques virtuels

Un volume entier dans un seul fichier .fdd : il se monte comme une lettre de lecteur, et peut être lu, vérifié et exporté sans montage. Il peut aussi résider dans une partition GPT que FileDO crée dans l’espace disque libre : disques GPT uniquement, taille fixe, pas plus rapide qu’un fichier, et chaque montage et chaque lecture demandent le consentement de l’administrateur - ce que ne fait plus une image vers un fichier. La fenêtre Gestionnaire de disques liste tous les disques au même endroit. Sans mot de passe, il est camouflé, pas chiffré. Windows uniquement ; le montage exige des droits d’administrateur, et la version Microsoft Store ne peut pas monter.

La fenêtre FileDO et le rapport d’assistance

Le ZIP et le paquet winget incluent filedo_win : un rail de tâches avec une page par tâche, plus une page Commande pour toute opération. Son bouton À propos regroupe les logs dans un ZIP et ouvre votre application de messagerie : vous voyez d’abord l’archive, et rien n’est envoyé tant que vous n’agissez pas.

Guides et détails

La référence complète reste ici pour ne pas concurrencer la première étape.

01Vérifier une clé USB/carte SD et la vitesse

Utilisez d’abord info. Un test de capacité crée des fichiers de test ; sélectionnez le bon disque et assurez-vous qu’il a assez d’espace libre.

filedo E: test del
filedo E: speed 100
02Doublons, copie et comparaison

Obtenez d’abord une liste ou un rapport. Les commandes avec del suppriment des données ; vérifiez le chemin et le résultat avant de les lancer.

filedo C:\Data check-duplicates
filedo C:\Source copy D:\Backup
filedo compare D:\Data E:\Backup
03Opérations à risque
Irréversible

wipe, fill … del et les modes de suppression de compare/duplicates peuvent supprimer des données. Inspectez d’abord le disque, la liste ou le rapport, et sauvegardez.

wipe vous demande de saisir WIPE. Les racines de disque/partage, les points d’analyse et le dossier TEMP du système exigent une confirmation interactive même avec --force.

04Compatibilité, éditions et installation
  • Distribution principale : Windows x64, la CLI filedo et des utilitaires associés.
  • winget et le ZIP portable incluent filedo, filedo_check, filedo_fill, filedo_test et l’interface graphique filedo_win.
  • Le MSI installe le même ensemble dans Program Files, plus PATH, les raccourcis et - à votre choix lors de l’installation - l’intégration à l’Explorateur. Les fonctionnalités se choisissent dans la fenêtre du programme d’installation ou avec ADDLOCAL pour une installation silencieuse, et Modifier dans Applications et fonctionnalités les change ensuite.
  • La compilation depuis les sources exige Go 1.24+.
git clone https://github.com/SerZhyAle/FileDO.git && cd FileDO && .\build.ps1

Le README contient le catalogue complet des commandes, les options de contrôle de lecture, des exemples réseau et les détails de l’interface graphique. GitHub Releases contient le setup EXE, le ZIP, le MSI et les fichiers SHA256 de chaque version.
