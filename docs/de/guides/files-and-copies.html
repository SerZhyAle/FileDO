Anleitung · Dateien und Ordner

Erst eine Liste oder einen Bericht holen. Später über das Löschen entscheiden.

FileDO hilft Ihnen, Duplikate, Unterschiede zwischen Ordnern und den Kopierfortschritt zu sehen. Ein guter erster Durchgang liefert eine klare Liste, einen Bericht oder eine Sicherungskopie - kein sofortiges Löschen.

Drei häufige Situationen

Speicherplatz freigeben

Übereinstimmende Dateien finden, die Liste speichern oder durchsehen und dann entscheiden, was bleibt.

filedo D:\Media check-duplicates

Eine Kopie anlegen, die Sie mitnehmen können

Kopieren Sie den Quellordner mit sichtbarem Fortschritt an einen Sicherungsort oder auf ein anderes Laufwerk. Das Kopieren beginnt mit der ersten gefundenen Datei; mit --precount wird zuerst der ganze Baum gezählt, damit Sie eine genaue Restzeit sehen.

filedo C:\Source copy D:\Backup

Einen Sicherungsordner prüfen

Zwei Ordner nach relativen Pfaden und Größen vergleichen, einen Bericht erhalten und die Unterschiede prüfen.

filedo compare D:\Data E:\Backup

Ein sicherer Weg

Löschen

Die del-Modi für Duplikate und Vergleich verändern Daten. Sie stehen absichtlich nicht im ersten Beispiel: Holen Sie zuerst eine Liste oder einen Bericht, sichern Sie dann und prüfen Sie den Pfad von Hand.

  1. Nennen Sie einen bestimmten Ordner statt eines ganzen Laufwerks, wenn die Aufgabe ein einzelnes Archiv betrifft.
  2. Führen Sie die Duplikatsuche oder den Vergleich ohne Löschmodus aus und sehen Sie das Ergebnis durch.
  3. Legen Sie vor jedem Löschen eine eigene Kopie der Dateien an, die Sie behalten wollen.

Was Vergleichen bedeutet

Der Vergleich gleicht relative Pfade und Dateigrößen ab; die Modi old/new nutzen die Änderungszeit. Der Pfadabgleich unter Windows unterscheidet nicht zwischen Groß- und Kleinschreibung. Berichte werden als compare_report_*.log gespeichert, Löschprotokolle als delete_report_<mode>_*.log.

Für eine automatisierte Prüfung nutzen Sie filedo compare D:\Data E:\Backup --strict: Übereinstimmende relative Pfade, Größen und Änderungszeiten ergeben Exit 0 (Passed), ein Unterschied ergibt Exit 1 (Failed), und ein unvollständiger Vergleich ergibt Exit 2 (Not proven). Mit --by-hash werden gleich große Paare nach Inhalt statt nach Zeit verglichen. Ein einfaches compare bleibt ein Bericht mit Exit 0 (Done); --strict lässt sich nicht mit dem Löschen kombinieren.
