Was hier nicht vorkommt

FileDO arbeitet mit lokalen Geräten, Ordnern, einzelnen Dateien und Windows-Netzwerkpfaden. SFTP, FTP und SSH werden nicht unterstützt. SFTP in Fast Media Sorter für Windows ist eine eigene Funktion: ausgewählte PC-Ordner für Android veröffentlichen.
