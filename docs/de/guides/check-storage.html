Anleitung · Speicher

Stellen Sie zuerst fest, was Sie vor sich haben: ein Laufwerk, einen Ordner oder ein Leseproblem.

Dieser Ablauf eignet sich für einen neuen USB-Stick, eine SD-Karte, eine externe Festplatte, einen Datenordner oder einen Netzwerkpfad. Er beginnt mit einem Befehl, der nur Informationen anzeigt.

Wann Sie ihn nutzen

Ein Laufwerk ist verdächtig billig, das Kopieren ist langsam, Dateien lassen sich nicht öffnen, oder Sie müssen den freien Speicherplatz und das Dateisystem kennen, bevor Sie ein Archiv verschieben.

Testdaten

test und speed verwenden Testdateien. Prüfen Sie Laufwerksbuchstaben und freien Speicherplatz. Das Suffix del bei test entfernt die Testdaten nach dem Lauf; es ersetzt keine Datensicherung.

Raw-Sondierung

probe nutzt direkten LBA-Zugriff, dauert etwa eine Minute und braucht Administratorrechte. Nutzen Sie es nicht als ersten Schritt: Führen Sie zuerst info und das reguläre test aus.

  1. Schließen Sie das Ziel an oder suchen Sie es und prüfen Sie, ob der Laufwerksbuchstabe stimmt.
  2. Informationen abrufen, ohne Daten zu ändern.
  3. Wählen Sie nur die nötige Prüfung: Kapazität, Geschwindigkeit oder Lesen von Dateien.
filedo E: info

Eine Prüfung wählen

USB/SD-Kapazität

Schreibt Testdaten und prüft sie, um ein Laufwerk zu erkennen, dessen angegebene Kapazität nicht nutzbar ist.

filedo E: test del

Geschwindigkeit

Misst Lesen und Schreiben mit Testdaten. Wählen Sie eine kleine Größe, wenn Sie schnell einen Anhaltspunkt brauchen.

filedo E: speed 100

Dateien lesen

Liest die Dateien eines Ordners und vermerkt Verzögerungen beim ersten Lesen; nützlich für eine alte Festplatte, einen USB-Stick oder ein Medienarchiv. --max-files N liest höchstens N Dateien (0 bedeutet unbegrenzt). --resume überspringt unveränderte Dateien auf der Liste der gut gelesenen; sind bereits alle Dateien geprüft, lautet das Ergebnis Passed, Exit 0, ohne erneutes Lesen.
