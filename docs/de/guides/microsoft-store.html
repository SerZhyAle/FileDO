Anleitung · Microsoft Store

Nutzen Sie FileDO aus dem Microsoft Store und wissen Sie, was diese Version nicht kann.

Die Microsoft-Store-Version ist dasselbe FileDO, vom Store installiert und aktualisiert: das FileDO-Fenster und der Befehl filedo. Sie ist eine paketierte App, und eine paketierte App kann weder den iSCSI-Initiator von Windows konfigurieren noch Administratorrechte anfordern; deshalb kann sie keine virtuellen Datenträger einbinden. Die meisten Einschränkungen stehen auch in der Anleitung zu der Funktion, die sie betreffen; diese Seite fasst sie an einer Stelle zusammen.

1. Beziehen

Installieren Sie FileDO von der Seite im Microsoft Store; danach hält der Store das Paket aktuell.

Microsoft Store

Vom Store installiert und aktualisiert und bei der Zertifizierung von Microsoft signiert. Diese Version kann keine virtuellen Datenträger einbinden und hat keine Einträge im Explorer-Menü; welche weiteren Funktionen fehlen, steht in Abschnitt 3.

Im Microsoft Store holen

Setup-EXE, MSI, ZIP und winget

Die anderen Versionen können virtuelle Datenträger einbinden. Die Setup-EXE, die MSI und das ZIP von GitHub sind nicht code-signiert; Windows kann deshalb beim ersten Start warnen.

Alle InstallationswegeWindows hat vor FileDO gewarnt

2. Was Sie bekommen

Ein Paket, zwei Zugänge: das FileDO-Fenster und der Befehl filedo.

Das FileDO-Fenster

Eine Seite für jede Aufgabe und eine Seite „Befehl“, die jeden beliebigen Befehl zusammenstellt und ausführt. Starten Sie es über das Startmenü.

Über ein Fenster arbeiten

Der Befehl filedo

Tippen Sie filedo in ein beliebiges Terminal. Hinter dem Fenster und dem Befehl läuft dieselbe Engine.

Dieselben Werkzeuge

Kapazitätstest, Geschwindigkeitstest, Duplikatsuche, Ordnervergleich und Kopieren, Löschen und Füllen sowie geheime Dateien sind in dieser Version genauso enthalten wie in den anderen.

Alle Anleitungen

3. Was diese Version nicht kann

Wo ein Bedienelement in dieser Version nie funktionieren könnte, lässt das Fenster es weg, statt es auszugrauen: Die Datenträgerverwaltung zeigt zum Beispiel keine Einbinden-Elemente. Die meisten dieser Einschränkungen stehen auch in der Anleitung zu der Funktion, die sie betreffen.

Kein Einbinden virtueller Datenträger

Eine paketierte App kann weder den iSCSI-Initiator von Windows konfigurieren noch Administratorrechte anfordern; diese Version kann deshalb keinen virtuellen Datenträger als Laufwerk einbinden. Befehle, die ein Einbinden brauchen, enden mit Exit-Code 6 (nicht unterstützt).

Was Windows liefern muss

Keine Partitionsdatenträger

Ein virtueller Datenträger kann in dieser Version nur in einer Datei liegen. vd disks sagt das, jeder Partitionsbefehl endet mit Exit-Code 6, und „Neuer Datenträger..“ in der Datenträgerverwaltung bietet nur die Datei an.

Partitionsdatenträger

Kein Teilen über Fast Media Sorter & Sharing

Das Teilen eines Datenträgers über Fast Media Sorter & Sharing ist in dieser Version gesperrt, und die Datenträgerverwaltung zeigt keine Teilen-Aktionen. Nutzen Sie dafür eine der anderen Versionen.

Was Sie zuerst brauchen

Keine Einträge im Explorer-Menü

Die Gruppe „File DO..“ im Rechtsklickmenü gehört nicht zu dieser Version: Eine paketierte Version kann sie nur über einen signierten Shell-Handler erhalten, und diese Version enthält keinen. Die Setup-EXE und die MSI fügen sie hinzu.

Installation und das Explorer-Menü

Windows-Einstellungen bleiben in Windows

Auf der Seite „Einstellungen“ öffnet „Beim Windows-Start ausführen“ die Windows-Einstellungen unter „Apps - Autostart“: Der Eintrag ist aus, bis Sie ihn dort einschalten, und auch der Task-Manager kann ihn verwalten. Die Schaltfläche „Automatische Wiedergabe von Windows deaktivieren“ wird nicht angeboten; stattdessen öffnet „Windows-Einstellungen zur automatischen Wiedergabe..“ die Windows-Seite.

Über ein Fenster arbeiten

4. Was mit Containern weiterhin funktioniert

Einen Container zu lesen und zu ändern braucht kein Einbinden und funktioniert deshalb hier.

.fd-sec-Container

Doppelklicken Sie eine .fd-sec-Datei: Das FileDO-Fenster öffnet sich auf der Seite „Geheime Datei öffnen“ mit bereits gewähltem Container, und dort wird nach dem Passwort gefragt.

Geheime Dateien

Virtuelle Datenträger (.fdd)

Doppelklicken Sie eine .fdd-Datei: Das FileDO-Fenster öffnet sich auf diesem Container und sagt deutlich, dass diese Version nicht einbinden kann. Sie können weiterhin einen Container anlegen, seine Infos lesen, ihn prüfen, exportieren, vergrößern, verkleinern, kopieren, sein Passwort ändern oder ihn entfernen - ohne Administratorrechte.

Ohne Einbinden lesen

5. Signatur, Berechtigungen und Daten

Dieser Abschnitt sagt dasselbe wie die Seite zur Windows-Warnung und die Datenschutzseite.

Von Microsoft signiert

Microsoft signiert das Paket bei der Zertifizierung; diese Version zeigt deshalb keine der Windows-Warnungen, die bei der Setup-EXE, der MSI und dem ZIP von GitHub erscheinen können: Diese sind nicht code-signiert.

Windows hat vor FileDO gewarnt

Eine Berechtigung, kein Netzwerk

Das Paket deklariert eine einzige Berechtigung, runFullTrust, die den direkten Zugriff auf den Datenträger erlaubt, und keine Internet-Berechtigung. FileDO sammelt nichts: keine Telemetrie, keine Analyse, keine Werbung, keine Konten.

Datenschutzseite öffnen

6. Wenn etwas fehlt oder nicht funktioniert

Prüfen Sie die Einschränkungen oben, bevor Sie eine fehlende Funktion melden. Wenn Sie etwas melden, nennen Sie die Microsoft-Store-Version: Die Versionen unterscheiden sich in dem, was sie können, und der Autor fragt, wie Sie FileDO installiert haben.
