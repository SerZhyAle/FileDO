FileDO ships one engine with two interfaces: the Windows window (filedo_win.exe) and the command line (filedo.exe). These three tables group common tasks by what they do to your data: read-only checks first, operations that write test files or copies second, and destructive operations last.FileDO поставляется как единый движок с двумя интерфейсами: окном Windows (filedo_win.exe) и командной строкой (filedo.exe). Три таблицы ниже группируют частые задачи по тому, как они влияют на данные: сначала проверки только на чтение, затем операции с записью тестовых файлов или копий и отдельно операции удаления и перезаписи.FileDO постачається як єдиний рушій із двома інтерфейсами: вікном Windows (filedo_win.exe) і командним рядком (filedo.exe). Три таблиці нижче групують типові завдання за тим, як вони впливають на дані: спочатку перевірки лише на читання, потім операції із записом тестових файлів чи копій і окремо операції видалення та перезапису.

2. Temporary test files, copies, backups, and containers2. Временные тестовые файлы, копии, архивы и контейнеры2. Тимчасові тестові файли, копії, архіви та контейнери

These operations write temporary test files into free space or create new destination files, containers, or virtual disks. Existing user files are kept unless you explicitly choose a removal flag.Эти операции записывают временные тестовые файлы в свободное место либо создают новые файлы, контейнеры или виртуальные диски. Существующие пользовательские файлы сохраняются, если вы явно не выбрали удаление оригинала.Ці операції записують тимчасові тестові файли у вільне місце або створюють нові файли, контейнери чи віртуальні диски. Наявні файли користувача зберігаються, якщо ви явно не вибрали видалення оригіналу.
