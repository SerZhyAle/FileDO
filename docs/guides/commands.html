The commandsКомандыКоманди

Ten commands cover what a script needs from FileDO. Most go to the running window program; commands and version answer on their own. Each prints its answer and ends with an exit code, so a script can branch on it. Every one is safe: it changes only FileDO’s own windows and runs and reads none of your files.Десять команд покрывают то, что скрипту нужно от FileDO. Большинство идут к запущенному окну; commands и version отвечают сами. Каждая печатает ответ и завершается кодом, по которому скрипт может ветвиться. Все они безопасны: меняют только окна и запуски самого FileDO и не читают ваши файлы.Десять команд покривають те, що скрипту потрібно від FileDO. Більшість ідуть до запущеного вікна; commands і version відповідають самі. Кожна друкує відповідь і завершується кодом, за яким скрипт може розгалужуватися. Усі вони безпечні: змінюють лише вікна й запуски самого FileDO та не читають ваших файлів.

What other programs may askО чём могут просить другие программыПро що можуть просити інші програми

Every command belongs to one of four risk classes. Safe changes only FileDO’s own windows and runs. Reads your data puts screen content, the clipboard, or file contents and names into an answer. Writes your data creates, changes or deletes your files or settings, or acts inside another program. Leaves the machine sends anything off this computer.Каждая команда относится к одному из четырёх классов риска. Безопасная меняет только окна и запуски самого FileDO. Читает ваши данные помещает в ответ содержимое экрана, буфер обмена либо содержимое и имена файлов. Пишет ваши данные создаёт, меняет или удаляет ваши файлы либо настройки или действует внутри другой программы. Выходит за пределы компьютера отправляет что-либо с этого компьютера.Кожна команда належить до одного з чотирьох класів ризику. Безпечна змінює лише вікна й запуски самого FileDO. Читає ваші дані поміщає у відповідь вміст екрана, буфер обміну або вміст та імена файлів. Пише ваші дані створює, змінює чи видаляє ваші файли або налаштування чи діє всередині іншої програми. Виходить за межі комп’ютера надсилає щось із цього комп’ютера.

The ten commands above, filedo_win.exe open and filedo_win.exe selftest run are safe, so a running FileDO accepts them (or opens the container in its own process) without any setting. The four developer tools that write a folder you name are in the class writes your data: they run in their own process when you start them yourself, and no other program can reach them through the running window.Десять команд выше, filedo_win.exe open и filedo_win.exe selftest run безопасны, поэтому запущенный FileDO принимает их (или открывает контейнер в собственном процессе) без всякой настройки. Четыре инструмента разработчика, пишущие в названную вами папку, относятся к классу пишет ваши данные: они выполняются в собственном процессе, когда вы запускаете их сами, и никакая другая программа не может добраться до них через запущенное окно.Десять команд вище, filedo_win.exe open та filedo_win.exe selftest run безпечні, тому запущений FileDO приймає їх (або відкриває контейнер у власному процесі) без жодного налаштування. Чотири інструменти розробника, що пишуть у названу вами теку, належать до класу пише ваші дані: вони виконуються у власному процесі, коли ви запускаєте їх самі, і жодна інша програма не може дістатися до них через запущене вікно.

Він вимкнений, доки ви його не ввімкнете, ввімкнути його можете лише ви, і жодна команда його не змінює. filedo status повідомляє, чи він увімкнений.

Same user, never the networkТот же пользователь, никогда не сетьТой самий користувач, ніколи не мережа

The commands travel over a local pipe that only your own Windows account, in your own session, can reach.
