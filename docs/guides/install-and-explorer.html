Двойной кликDouble-clickПодвійний клік

Двойной клик по .fd-sec - это ровно пункт меню «Unsecure and start»: открывается окно консоли, которое спрашивает пароль, восстанавливает оригинал под его настоящим именем в %LOCALAPPDATA%\FileDO\reveal - папку, которую можете читать только вы и система, - и сразу открывает его в той программе, которой принадлежит настоящее расширение: запакованный .txt откроется в вашем редакторе текста, видео - в плеере. Копия удаляется, когда вы закрываете это окно консоли; если программа всё ещё держит файл открытым, копию уберёт следующий запуск FileDO. Контейнер никуда не девается. Нужен постоянный файл - Unsecure без start, он возвращает оригинал рядом с контейнером навсегда. Отдельного пункта меню для двойного клика нет и не нужно - по расширению срабатывает ассоциация. Исполняемые файлы и скрипты, восстановленные так, открываются как обычный двойной клик по ним и открыл бы - без отдельного запрета для этого пути.Double-clicking a .fd-sec is exactly the "Unsecure and start" menu entry: a console window opens, asks for the password, restores the original under its true name into %LOCALAPPDATA%\FileDO\reveal - a folder only you and the system can read - and opens it right away in whatever program owns its real extension: a packed .txt opens in your text editor, a video in your player. The copy is removed when you close that console window; if the program still has the file open, the next FileDO start removes it. The container is left in place. When you want the file to stay, use Unsecure without start - it brings the original back beside the container for good. There is no separate menu entry for the double-click and there needs to be none - the extension's own association is what runs. An executable or script restored this way opens exactly as an ordinary double-click on it would - there is no extra refusal on this path.Подвійний клік по .fd-sec - це рівно пункт меню «Unsecure and start»: відкривається вікно консолі, яке запитує пароль, відновлює оригінал під його справжнім ім'ям у %LOCALAPPDATA%\FileDO\reveal - теку, яку можете читати лише ви та система, - і одразу відкриває його в тій програмі, якій належить справжнє розширення: запакований .txt відкриється у вашому редакторі тексту, відео - у плеєрі. Копія видаляється, коли ви закриваєте це вікно консолі; якщо програма ще тримає файл відкритим, копію прибере наступний запуск FileDO. Контейнер нікуди не дівається. Потрібен постійний файл - Unsecure без start, він повертає оригінал поруч із контейнером назавжди. Окремого пункту меню для подвійного кліку немає й не треба - за розширенням спрацьовує асоціація. Виконувані файли та скрипти, відновлені так, відкриваються так само, як їх відкрив би звичайний подвійний клік - без окремої заборони на цьому шляху.
