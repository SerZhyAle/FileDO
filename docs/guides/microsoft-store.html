Use FileDO from the Microsoft Store, and know what that build cannot do.Пользуйтесь FileDO из Microsoft Store и знайте, чего в этой сборке нет.Користуйтеся FileDO з Microsoft Store і знайте, чого в цій збірці немає.

The Microsoft Store build is the same FileDO, installed and updated by the Store: the FileDO window and the filedo command. It is a packaged app, and a packaged app can neither configure the iSCSI initiator of Windows nor ask for administrator rights, so it cannot mount virtual disks. Most of the limits are also stated in the guide of the function they touch; this page gathers them in one place.Сборка из Microsoft Store - тот же FileDO, который устанавливает и обновляет Store: окно FileDO и команда filedo. Это упакованное приложение, а упакованное приложение не может ни настроить инициатор iSCSI в Windows, ни запросить права администратора, поэтому подключать виртуальные диски оно не умеет. Большинство ограничений описано и в руководстве по той возможности, которой они касаются; здесь они собраны в одном месте.Збірка з Microsoft Store - це той самий FileDO, який встановлює й оновлює Store: вікно FileDO і команда filedo. Це запакований застосунок, а запакований застосунок не може ні налаштувати ініціатор iSCSI у Windows, ні попросити права адміністратора, тому підключати віртуальні диски він не вміє. Більшість обмежень описано й у посібнику з тієї можливості, якої вони стосуються; тут їх зібрано в одному місці.

3. What this build does not do3. Чего эта сборка не делает3. Чого ця збірка не робить

Where a control could never work in this build, the window leaves it out instead of greying it out: the Disk manager, for example, shows no mount controls. Most of these limits are also stated in the guide of the function they touch.Если элемент управления в этой сборке никогда не заработает, окно его не показывает, а не делает серым: например, в Диспетчере дисков нет элементов подключения. Большинство этих ограничений описано и в руководстве по той возможности, которой они касаются.Якщо елемент керування в цій збірці ніколи не запрацює, вікно його не показує, а не робить сірим: наприклад, у Диспетчері дисків немає елементів підключення. Більшість цих обмежень описано й у посібнику з тієї можливості, якої вони стосуються.

No mounting of virtual disksНет подключения виртуальных дисковНемає підключення віртуальних дисків

A packaged app can neither configure the iSCSI initiator of Windows nor ask for administrator rights, so this build cannot mount a virtual disk as a drive. The commands that need a mount end with exit code 6 (unsupported).Упакованное приложение не может ни настроить инициатор iSCSI в Windows, ни запросить права администратора, поэтому эта сборка не может подключить виртуальный диск буквой диска. Команды, которым нужно подключение, заканчиваются кодом 6 (не поддерживается).Запакований застосунок не може ні налаштувати ініціатор iSCSI у Windows, ні попросити права адміністратора, тому ця збірка не може підключити віртуальний диск літерою диска. Команди, яким потрібне підключення, закінчуються кодом 6 (не підтримується).

FileDO collects nothing: no telemetry, no analytics, no ads, no accounts.Пакет объявляет одну возможность, runFullTrust, которая даёт прямой доступ к диску, и не объявляет доступа в интернет.
