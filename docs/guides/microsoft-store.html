Сборка из Microsoft Store - тот же FileDO, который устанавливает и обновляет Store: окно FileDO и команда filedo. Это упакованное приложение, а упакованное приложение не может ни настроить инициатор iSCSI в Windows, ни запросить права администратора, поэтому подключать виртуальные диски оно не умеет. Большинство ограничений описано и в руководстве по той возможности, которой они касаются; здесь они собраны в одном месте.The Microsoft Store build is the same FileDO, installed and updated by the Store: the FileDO window and the filedo command. It is a packaged app, and a packaged app can neither configure the iSCSI initiator of Windows nor ask for administrator rights, so it cannot mount virtual disks. Most of the limits are also stated in the guide of the function they touch; this page gathers them in one place.Збірка з Microsoft Store - це той самий FileDO, який встановлює й оновлює Store: вікно FileDO і команда filedo. Це запакований застосунок, а запакований застосунок не може ні налаштувати ініціатор iSCSI у Windows, ні попросити права адміністратора, тому підключати віртуальні диски він не вміє. Більшість обмежень описано й у посібнику з тієї можливості, якої вони стосуються; тут їх зібрано в одному місці.

3. Чего эта сборка не делает3. What this build does not do3. Чого ця збірка не робить

Если элемент управления в этой сборке никогда не заработает, окно его не показывает, а не делает серым: например, в Диспетчере дисков нет элементов подключения. Большинство этих ограничений описано и в руководстве по той возможности, которой они касаются.Where a control could never work in this build, the window leaves it out instead of greying it out: the Disk manager, for example, shows no mount controls. Most of these limits are also stated in the guide of the function they touch.Якщо елемент керування в цій збірці ніколи не запрацює, вікно його не показує, а не робить сірим: наприклад, у Диспетчері дисків немає елементів підключення. Більшість цих обмежень описано й у посібнику з тієї можливості, якої вони стосуються.

Нет подключения виртуальных дисковNo mounting of virtual disksНемає підключення віртуальних дисків

Упакованное приложение не может ни настроить инициатор iSCSI в Windows, ни запросить права администратора, поэтому эта сборка не может подключить виртуальный диск буквой диска. Команды, которым нужно подключение, заканчиваются кодом 6 (не поддерживается).A packaged app can neither configure the iSCSI initiator of Windows nor ask for administrator rights, so this build cannot mount a virtual disk as a drive. The commands that need a mount end with exit code 6 (unsupported).Запакований застосунок не може ні налаштувати ініціатор iSCSI у Windows, ні попросити права адміністратора, тому ця збірка не може підключити віртуальний диск літерою диска. Команди, яким потрібне підключення, закінчуються кодом 6 (не підтримується).

Подписано MicrosoftSigned by MicrosoftПідписано Microsoft

Microsoft подписывает пакет при сертификации, поэтому эта сборка не показывает предупреждений Windows, которые могут появиться у Setup EXE, MSI и ZIP с GitHub: те не подписаны цифровым сертификатом.Microsoft signs the package at certification, so this build shows none of the Windows warnings that the setup EXE, the MSI and the ZIP from GitHub can show: those are not code-signed.Microsoft підписує пакет під час сертифікації, тому ця збірка не показує попереджень Windows, які можуть з'явитися у Setup EXE, MSI і ZIP з GitHub: ті не підписані цифровим сертифікатом.
