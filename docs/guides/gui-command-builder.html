FileDO GUI — это Windows Forms-конструктор для тех же команд FileDO. Он не меняет правила безопасности: он делает путь, операцию и будущую команду видимыми до запуска.FileDO GUI is a Windows Forms builder for the same FileDO commands. It does not change safety rules: it makes the path, operation, and future command visible before execution.FileDO GUI — це Windows Forms-конструктор для тих самих команд FileDO. Він не змінює правил безпеки: він робить шлях, операцію та майбутню команду видимими перед запуском.

Что показывает окноWhat the window exposesЩо показує вікно

В одном окне доступны info, speed, test, fill, clean, дубликаты, семейство copy, wipe, compare, check, probe, recover, from и hist. Для операций копирования и сравнения появляются поля источника и назначения. Контекстные флаги показывают только относящиеся к выбранной операции параметры, а справочная панель объясняет ожидаемый результат и пример.One window offers info, speed, test, fill, clean, duplicates, the copy family, wipe, compare, check, probe, recover, from, and hist. Copy and compare expose source and destination fields. Contextual flags show parameters relevant to the selected operation, while the help panel explains the expected result and gives an example.В одному вікні доступні info, speed, test, fill, clean, дублікати, сімейство copy, wipe, compare, check, probe, recover, from і hist. Для копіювання та порівняння з’являються поля джерела й призначення. Контекстні прапорці показують параметри, що стосуються вибраної операції, а довідкова панель пояснює очікуваний результат і наводить приклад.

Та же ответственностьSame responsibilityТа сама відповідальність

GUI не делает wipe, fill … del или режимы удаления обратимыми. Перед Run проверьте цель и preview; для необратимых действий сделайте резервную копию.The GUI does not make wipe, fill … del, or deletion modes reversible. Check the target and preview before Run; back up before irreversible actions.GUI не робить wipe, fill … del або режими видалення зворотними.
