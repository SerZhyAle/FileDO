Чего здесь нетWhat is not hereЧого тут немає

FileDO работает с локальными устройствами, папками, отдельными файлами и сетевыми путями Windows. Поддержки SFTP, FTP или SSH в продукте нет. SFTP в Fast Media Sorter for Windows - другая, отдельная возможность: публикация выбранных папок ПК для Android.FileDO works with local devices, folders, individual files, and Windows network paths. It does not support SFTP, FTP, or SSH. SFTP in Fast Media Sorter for Windows is a separate capability: publishing selected PC folders for Android.FileDO працює з локальними пристроями, папками, окремими файлами й мережевими шляхами Windows. Підтримки SFTP, FTP або SSH у продукті немає. SFTP у Fast Media Sorter for Windows - окрема можливість: публікація вибраних папок ПК для Android.
