Тест ёмкостиCapacity testТест ємності
Записывает тестовые данные и читает их обратно, доказывая, сколько носитель хранит на самом деле. Так находят поддельный накопитель. filedo E: test - проверка носителя.Writes test data and reads it back, proving how much a drive really stores. It is how a fake drive is caught. filedo E: test - checking storage.Записує тестові дані й читає їх назад, доводячи, скільки носій зберігає насправді. Так знаходять підроблений накопичувач. filedo E: test - перевірка носія.
Поддельный накопительFake driveПідроблений накопичувач
Флешка или карта, которая сообщает больше места, чем может хранить: данные сверх настоящего объёма теряются молча. Её показывает только тест ёмкости.A USB drive or card that reports more space than it can hold: data written past the real size is lost without a word. Only a capacity test shows it.Флешка чи картка, що повідомляє більше місця, ніж може зберігати: дані понад справжній обсяг губляться мовчки. Її показує лише тест ємності.
ЗаполнениеFillЗаповнення
Пишет тестовые файлы, пока не закончится свободное место. С del они потом удаляются - и старое свободное место при этом перезаписано. filedo D: fill 1000 delWrites test files until the free space is used up. With del they are removed afterwards, and the old free space has been overwritten on the way. filedo D: fill 1000 delПише тестові файли, доки не скінчиться вільне місце. З del їх потім видаляють - і старе вільне місце при цьому перезаписане. filedo D: fill 1000 del
ЗатираниеWipeЗатирання
Перезаписать на месте, затем удалить - не обычное удаление. Всегда просит напечатать WIPE. На SSD и файловых системах с копированием при записи оно снижает шансы восстановления и ничего не обещает.Overwrite in place, then remove - not an ordinary delete. It always asks you to type WIPE. On SSDs and copy-on-write file systems it lowers the odds of recovery and promises nothing.Перезаписати на місці, потім видалити - не звичайне видалення. Завжди просить надрукувати WIPE. На SSD і файлових системах із копіюванням під час запису воно знижує шанси відновлення й нічого не обіцяє.
Контейнер .fd-sec.fd-sec containerКонтейнер .fd-sec
Один файл или папка под одним паролем в одном файле .fd-sec. Настоящее имя, размер и отметки времени запечатаны внутри. Секретные файлы.One file or folder under one password, in one .fd-sec file. The true name, the size and the timestamps are sealed inside. Secret files.Один файл чи тека під одним паролем в одному файлі .fd-sec. Справжнє ім'я, розмір і позначки часу запечатані всередині. Секретні файли.
Сделать секретным (secure)Secure (secure)Зробити секретним (secure)
Упаковать файл или папку в контейнер рядом. Оригинал остаётся, пока вы не попросите его убрать (del или wipe).Pack a file or folder into a container beside it. The original stays until you ask for it to go (del or wipe).Запакувати файл чи теку в контейнер поруч. Оригінал лишається, доки ви не попросите його прибрати (del або wipe).
Вернуть оригинал (unsecure)Unsecure (unsecure)Повернути оригінал (unsecure)
Вернуть оригинал из контейнера навсегда - под запечатанным именем и с его отметками времени. Существующий файл никогда не перезаписывается молча.Bring the original back out of a container for good - under its sealed name and with its own timestamps. An existing file is never overwritten silently.Повернути оригінал із контейнера назавжди - під запечатаним іменем і з його позначками часу. Наявний файл ніколи не перезаписується мовчки.
Открыть, не распаковывая (reveal)Reveal (reveal)Відкрити, не розпаковуючи (reveal)
Открыть содержимое в его программе из временной копии, которая потом убирается: после просмотра ничего не остаётся.Open the content in its own program from a temporary copy that is taken away again: nothing is kept after the look.Відкрити вміст у його програмі з тимчасової копії, яку потім прибирають: після перегляду нічого не лишається.
