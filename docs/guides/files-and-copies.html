Безопасный маршрутA safe routeБезпечний маршрут

  1. Укажите конкретную папку, а не весь диск, если задача относится только к одному архиву.Name a specific folder rather than an entire drive when the task concerns one archive.Укажіть конкретну папку, а не весь диск, якщо завдання стосується одного архіву.
  2. Запустите поиск дубликатов или сравнение без режима удаления и просмотрите итог.Run duplicate search or comparison without a deletion mode and review the result.Запустіть пошук дублікатів або порівняння без режиму видалення й перегляньте результат.
  3. Перед любым удалением сделайте отдельную копию файлов, которые хотите сохранить.Before any deletion, make a separate copy of files you intend to keep.Перед будь-яким видаленням зробіть окрему копію файлів, які хочете зберегти.

Режимы del для дубликатов и сравнения меняют данные. Они намеренно не показаны как первый пример: сначала нужен список или отчёт, затем резервная копия и ручная проверка пути.del modes for duplicates and comparison change data. They are intentionally not shown as a first example: get a list or report first, then back up and manually check the path.Режими del для дублікатів і порівняння змінюють дані. Їх навмисно не показано першим прикладом: спочатку потрібен список або звіт, потім резервна копія та ручна перевірка шляху.

Что именно сравниваетсяWhat comparison meansЩо означає порівняння

Сравнение сопоставляет относительные пути и размер файлов; для режимов «старый/новый» используется время изменения. В Windows имена путей сравниваются без учёта регистра. Отчёты сохраняются как compare_report_*.log, а журналы удаления — как delete_report_<mode>_*.log.Comparison matches relative paths and file size; old/new modes use modification time. Windows path matching is case-insensitive. Reports are saved as compare_report_*.log, while deletion logs use delete_report_<mode>_*.log.Порівняння зіставляє відносні шляхи та розмір файлів; для режимів «старий/новий» використовується час зміни. У Windows шляхи порівнюються без урахування регістру. Звіти зберігаються як compare_report_*.log, а журнали видалення — як delete_report_<mode>_*.log.
