A Windows tool for checking the real capacity and speed of USB, SD, and HDD storage, reading files, finding duplicates, comparing folders, copying, and cleanup. wipe требует ввода WIPE. Для корней дисков/шар, reparse points и системной TEMP-папки нужно интерактивное подтверждение даже с --force.wipe asks you to type WIPE. Drive/share roots, reparse points, and the system TEMP folder require interactive confirmation even with --force.wipe просить ввести WIPE. Корені дисків/ресурсів, reparse points і системна TEMP-папка потребують інтерактивного підтвердження навіть із --force.
