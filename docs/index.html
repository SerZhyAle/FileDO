# Key features

Everything FileDO does, packed into one small executable. No dependencies, no telemetry.

Fake-Capacity Detection
  • 100-file verification, 1% capacity each
  • Random position checks on every run
  • Defeats sophisticated fake controllers
  • Fast raw LBA probe (~1 min)
Speed Testing
  • Real read / write throughput
  • Memory-optimized buffers
  • Live progress with ETA
  • Test files from 1 MB to 100 GB
Duplicate Management
  • MD5 hash-based identification
  • Oldest / newest / alphabetical modes
  • Delete or move duplicates
  • Hash cache for fast re-scans
Copy Operations
  • Progress tracking with ETA
  • Timeout protection on stalls
  • Preserves metadata & timestamps
  • Devices, folders, shares and files
Fast & Secure Wipe
  • Ultra-fast folder wipe
  • High-speed secure fill (4.7+ GB/s)
  • WIPE confirmation guardrails
  • Protects roots, junctions and TEMP
Compare & Health Check
  • Compare two folders + report
  • Delete by old / new / small / big
  • Fast read health check
  • Batch mode from command files

# Quick start

One verb, any target. Copy a command and go.

01Check if a USB / SD card is fake
filedo E: test del
02Benchmark drive speed
filedo C: speed 100
03Securely wipe free space
filedo D: fill 1000 del
04Find duplicate files
filedo C: check-duplicates
05Copy a folder with progress
filedo C:\Source copy D:\Backup
06Fast-wipe a folder's contents
filedo C:\Temp wipe
